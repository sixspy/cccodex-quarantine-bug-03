## 回炉开跑（切流账册）

工程形态选定 **切流账册**，双写两轨与半修脚手架已移除，两套读轨不并存。

- **开跑落点**：每张回炉单执行时在 `rework_run_ledger` 落一行，锁当刻条目键 + 64 位指纹，`ON CONFLICT(row_id) DO NOTHING` + `BEGIN IMMEDIATE` 保证同一单只落定一次，双人争抢只有一人成。
- **开跑芯片**：`待开跑` / `执行中` / `已清空`，由账册与回炉中余数推出，不再手写冒充。
- **回炉中余数**：尚未出回炉的隔离行数；对账报告与开跑芯片同源。
- **读轨**：落定后切到 `cutover_book` 并拒绝回刷。
- **入库闸门**：读轨、指纹、芯片、余数四者不齐即挡清洗入库；回炉件在余数清零前一律拒吞。

开跑落点、芯片、余数三者在回炉页分开展示；抓取批次页亮回炉中余数，隔离舱卡片旁挂策略页入口，台参数页只读回看开跑口径。
